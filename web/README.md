# 어따뒀지 — 아이폰용 웹앱 (PWA)

`https://dacisosl.github.io/CARwhere/` — GitHub Pages로 서빙된다 (`.github/workflows/pages.yml`).

## 왜 웹앱인가

APK는 안드로이드 전용 패키지라 아이폰에 설치되지 않는다. iOS는 `.ipa` + Apple 서명이
필요하고, 배포에는 Mac + Xcode + Apple 개발자 계정(연 $99) + App Store/TestFlight 심사가 따른다.
그래서 아이폰에서 **지금 당장** 쓸 수 있는 길은 홈 화면에 추가하는 웹앱뿐이다.

## 안드로이드판과 다른 점

| | 안드로이드 | 아이폰(웹앱) |
|---|---|---|
| 하차 자동감지 | 차량 블루투스 끊김으로 자동 | **불가** — 사파리에 Web Bluetooth·백그라운드 실행이 없다 |
| 기록 | 자동으로 시트가 뜸 | 홈 아이콘 → 층수 탭 → [주차] (3초) |
| 상태바 캡슐·위젯 | 있음 | 없음 (웹앱은 상태바·위젯에 접근 못 함) |
| 층·메모·사진·지도 | 있음 | 있음 |
| 저장 | 앱 내부 저장소 + Room | `localStorage` (이 폰에만, 서버 없음) |

## 구조 — 의존성 0

- `index.html` — 앱 전체(마크업·CSS·JS 한 파일). 외부 스크립트를 쓰지 않는다.
  Leaflet 같은 지도 라이브러리를 CDN에서 불러오면 그 CDN이 막히거나 오프라인일 때
  스크립트 예외로 **앱 전체가 멈춘다** — 실제로 그렇게 죽는 것을 보고 걷어냈다.
  지도는 OSM 타일 URL 규칙(`/{z}/{x}/{y}.png`)만 써서 직접 그린다: 타일이 안 와도
  층수·경과시간·메모는 그대로 보인다.
- `sw.js` — 앱 셸만 캐시(네트워크 우선 + 실패 시 캐시). 지도 타일·폰트는 캐시하지 않는다.
- `manifest.webmanifest` — 홈 화면 추가 시 standalone 실행, 아이콘.
- Pretendard는 CDN 웹폰트로 불러오고, 실패하면 시스템 폰트(-apple-system)로 떨어진다.

## 차 끄면 자동으로 뜨게 — iOS 단축어 자동화

사파리는 차량 블루투스를 못 보지만, **단축어 앱의 자동화는 본다.** 그래서 감지 자체는
iOS에 맡기고 앱은 링크로 열리기만 하면 된다 — 안드로이드판의 체감에 가장 가까운 방법.

| 트리거 (단축어 → 자동화 → +) | 동작 | 결과 |
|---|---|---|
| **블루투스** → 차 오디오 → "연결 해제될 때" | URL 열기 → `…/?record=1` | 차에서 내리면 앱이 열리고 **기록 시트가 바로 뜬다** |
| **CarPlay** → "연결 해제될 때" | 같음 | 카플레이 차량이면 더 정확 |
| **도착** → 집·주차장 주소 | URL 열기 `…/?record=1` 또는 **알림 표시** | 집 근처에 오면 기록하라고 알려준다 |
| **블루투스** → "연결될 때" | URL 열기 → `…/?depart=1` | 차를 타면 출차로 기록 (되돌리기 버튼 제공) |

- 자동화는 **"즉시 실행"**(실행 전 확인 끄기)으로 만들어야 확인 없이 돈다.
- 잠금 상태에서는 알림으로 먼저 뜨고, 탭하면 기록 시트가 열린다.
- 지오펜싱(도착 감지)은 iOS가 하므로 **앱이 꺼져 있어도** 동작한다 — 웹앱 스스로는 못 하는 일이다.

앱을 열었을 때 등록한 주차장 120m 안이고 기록이 없으면, 홈에 "집 주차장이에요 — 지금 기록할까요?"
배너가 뜬다 (단축어 없이도 한 단계 줄여준다).

## 웹앱이 못 하는 것 (정직하게)

- 백그라운드 위치 감시·지오펜싱: 브라우저에 API가 없다 (`watchPosition`은 화면이 꺼지면 멈춘다)
- 예약 알림·차량 블루투스 감지: iOS 사파리에 없다
- 웹 푸시는 iOS 16.4+ 홈 화면 앱에서 되지만 **보낼 서버가 필요**하고, 그래도 위치를
  백그라운드에서 볼 수 없어 "집에 도착하면"을 판단할 주체가 없다 → 그래서 단축어를 쓴다

## 아이폰에서 앱처럼 쓰기

1. 사파리로 위 주소 열기
2. 화면 아래 **공유 버튼**(위로 향한 화살표) 탭
3. **"홈 화면에 추가"** 선택 → 홈 아이콘으로 열면 주소창 없이 앱처럼 열린다

크롬(iOS)에서는 "홈 화면에 추가"가 사파리와 동작이 다르므로 사파리를 쓰는 편이 낫다.
