주차 기록
앱 정보

아이폰판은 수동 기록입니다. 사파리에는 차량 블루투스 API가 없어서, 안드로이드판처럼 차에서 내리는 순간을 자동으로 알아채지는 못합니다. 대신 홈 화면 아이콘 한 번 → [주차] 한 번으로 3초 안에 기록됩니다.

앱처럼 쓰는 방법

  1. 사파리 화면 아래 공유 버튼(위로 향한 화살표) 탭
  2. "홈 화면에 추가" 선택
  3. 홈 화면 아이콘으로 열면 사파리 주소창 없이 앱처럼 열립니다

기록은 이 폰에만 저장됩니다. 서버로 아무것도 보내지 않습니다. 사파리 데이터를 지우면 기록도 함께 사라집니다.

위치는 [주차]를 누를 때 한 번만 조회합니다 — 상시 추적하지 않습니다.

안드로이드폰이라면 자동감지가 되는 정식 앱을 쓰세요.
