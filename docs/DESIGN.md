# DESIGN v2 — 주차어디 (구 어따뒀지)

콘크리트 + 형광 사인 테마 유지하되, "자동차 계기판(클러스터)" 무드를 입힌다.
지금까지의 문제: 자동차 앱 같지 않고 일반 유틸 앱 같음 → v2에서 해결.

## 0. v2 변경 요약

1. safe area 대응: 상태바/내비바 영역 침범 금지 (systemBarsPadding)
2. 자동차 계기판 무드: 원형 게이지형 층수 표시, 레터스페이싱, "PARKED" 라벨
3. 팝업을 헤드업 알림 → 화면 하단 1/3 바텀시트로 (다른 앱 위에 표시)
4. 상태바 표시를 형광 그린 필(pill)로 감싸기
5. 대시보드에 최근 주차 기록 + 인라인 설정 토글(아래로 펼침)
6. 홈 위젯 추가 (상태바와 병행)
7. 층+메모 표시 ("B3 · C구역 · 기둥 27 옆")
8. 앱 아이콘: 자동차/주차 모티프

## 1. 디자인 원칙 (v2)

1. 버튼 최소화 — 한 화면에 결정 하나 (유지)
2. 층 선택/표시는 세로 스택, 건물 단면 메타포 (유지)
3. 형광(#97C459)은 한 화면에 1~2개 (유지)
4. [신규] 자동차 계기판 어휘 사용: 원형 게이지, 대문자 레터스페이싱 라벨(PARKED, DETECTING),
   상단 "● 감지 중" 상태 인디케이터 — 시동 걸린 차 같은 느낌
5. [신규] 모든 화면 edge-to-edge + WindowInsets 패딩. 콘텐츠가 시스템 바에 깔리지 않게

## 3. 화면별 스펙 v2

### 대시보드 v4.2 (사용자 스케치 기반 — 현재 구현)
세 장의 카드가 세로로 쌓이고, 내용이 길어지면 화면 전체가 스크롤된다.
1. 헤더: 앱 이름(레터스페이싱) + 우측 "● 감지 중" 배지 + 아래 "마지막 차량 신호 · 시각 연결/끊김" 진단 줄
2. 주차 카드:
   - 좌: 엔진 스타트 버튼(층수 + PARKED) — 누르면 '다시 기록' (주차 전이면 수동 기록)
   - 우: 내 차 배지 — 앱 아이콘에서 고른 차종·색 그대로, 주차 중이면 네온 링 점등
   - 가운데 한 줄: 위치명 · 구역 · 메모
   - 하단: [사진 보기] [+02:19 경과시간 — 트립미터 표기, 디스플레이 폰트]
3. 지도 카드:
   - 상단: "위치" + 저장된 위치 칩(집·학교…, 가로 스크롤, 현재 위치는 네온 테두리) + "+" 추가 칩 — 탭하면 수정 모달
   - 본문: GPS 지도(OSM 타일, 다크 테마는 색 반전). 차 마커 + 내 위치 점 + 점선,
     좌하단 "차까지 320m · 북동쪽" 필과 방향 화살표. 프리뷰 전용 — 탭하면 지도 앱으로 길찾기
   - 내 위치는 화면 복귀 시 1회만 조회 (절대 규칙 6), 차 좌표는 주차 확정 시 1회 저장분
4. 설정 카드:
   - "설정 · 즐겨찾기" + 우측 "모든 설정 →"
   - ★ 즐겨찾기 행은 항상 표시 (많아지면 카드가 길어지고 전체 스크롤)
   - 왼쪽 아래 "▸ 더 보기" → 아코디언: 나머지 빠른 설정, 최근 주차 카드 토글, 내 차 블루투스, 배터리 예외
- 형광은 엔진 버튼 링 / 내 차 링 / 감지 LED / 현재 위치 칩 테두리까지 (절대 규칙 3의 상한 안에서 상태 표시에만)

### 대시보드 v2 (이전 스펙 — 참고)
위에서 아래 순서:
1. 헤더: 앱 이름(레터스페이싱 2px) + 우측 "● 감지 중" 형광 상태 배지
2. 메인 카드 (계기판):
   - 좌측: 원형 게이지 (형광 테두리 3px, 안에 층수 24px + "PARKED" 9px 라벨)
   - 우측: 장소명 / 구역+메모 (map-pin 아이콘) / 시각+경과 (clock 아이콘)
   - 하단: [사진] [다시 기록] 버튼 2개
3. 최근 주차 카드: 최근 2~3건 (날짜·장소 | 층). 탭하면 전체 히스토리 화면
4. 설정 카드: 접힌 상태가 기본, 탭하면 아래로 펼쳐짐 (인라인 토글)
   - 여기엔 자주 쓰는 토글 3개만: 기압 자동감지(베타) / 위젯+상태바 / 출차 시 자동 삭제
   - "모든 설정" 링크로 전체 설정 화면 진입
- 주차 기록 없을 때: 게이지가 회색, 안에 "—" 표시, "지금 주차 중이 아니에요"

### 팝업 (바텀시트로 전면 변경)
- 다른 앱 사용 중에도 화면 하단 약 1/3을 덮는 바텀시트로 등장
  (SYSTEM_ALERT_WINDOW "다른 앱 위에 표시" 권한 — 온보딩 2단계에 추가)
- 시야를 살짝 가리는 게 의도: 불편해서라도 층 버튼을 누르게 됨
- 그 자리에서 층 버튼 바로 탭 — 모달 위 모달 금지
- 구성: 드래그 핸들 / "주차 감지 — 몇 층?" + 작은 카메라 버튼 /
  층 버튼 세로 스택 / 하단 힌트
- 기압 자동감지 켠 경우: 추정 층이 미리 형광 강조 + "기압 추정" 라벨. 탭 1번으로 확정
- 위로 쓸어올리면 확장 → 구역/메모 입력 필드
- 10초 무응답 → 시트 내려가고 "위치만 저장됨"
- 알림 권한만 있고 오버레이 권한 없는 유저 → 기존 헤드업 알림으로 폴백

### 상태바 표시
- 형광 그린 필: 배경 #97C459, 텍스트 #173404, 차 아이콘 + "B3"
- 주의: 안드로이드 상태바 아이콘은 시스템이 단색 처리함 → 필 스타일은
  잠금화면/알림 축소 뷰와 홈 위젯에서 구현하고, 상태바 자체는 "P·B3" 텍스트 아이콘 유지
- 알림 확장 뷰: "B3 · C구역 · 기둥 27 옆 · 1시간 20분" + [사진 보기] 액션

### 홈 위젯 (신규)
- 2x1: 형광 필 스타일 "🚗 B3 · 스타필드" — 탭하면 대시보드
- 1x1: 원형 게이지 미니 버전 (층수만)
- 주차 없을 땐 회색 "기록하기" 버튼 역할 (수동 기록 진입점)

### 앱 아이콘 (3안 중 택1, 모두 #1E1E1C 배경)
- A: 형광 자동차 실루엣
- B: 형광 테두리 P 사인 (주차 표지판)
- C: 건물 단면 3줄 중 가운데만 형광 + 미니 차 (시그니처 그래픽 연장) ← 추천
