# DESIGN v2 — 주차어디 (구 어따뒀지)

콘크리트 + 형광 사인 테마 유지하되, "자동차 계기판(클러스터)" 무드를 입힌다.
지금까지의 문제: 자동차 앱 같지 않고 일반 유틸 앱 같음 → v2에서 해결.

## 0. v2 변경 요약

1. safe area 대응: 상태바/내비바 영역 침범 금지 (systemBarsPadding)
2. 자동차 계기판 무드: 원형 게이지형 층수 표시, 레터스페이싱, "PARKED" 라벨
3. 팝업을 헤드업 알림 → 화면 하단 1/3 바텀시트로 (다른 앱 위에 표시)
4. 상태바 표시를 형광 그린 필(pill)로 감싸기
5. 대시보드에 최근 주차 기록 + 인라인 설정 토글(아래로 펼침)
6. 홈 위젯 추가 (상태바와 병행)
7. 층+메모 표시 ("B3 · C구역 · 기둥 27 옆")
8. 앱 아이콘: 자동차/주차 모티프

## 1. 디자인 원칙 (v2)

1. 버튼 최소화 — 한 화면에 결정 하나 (유지)
2. 층 선택/표시는 세로 스택, 건물 단면 메타포 (유지)
3. 형광(#97C459)은 한 화면에 1~2개 (유지)
4. [신규] 자동차 계기판 어휘 사용: 원형 게이지, 대문자 레터스페이싱 라벨(PARKED, DETECTING),
   상단 "● 감지 중" 상태 인디케이터 — 시동 걸린 차 같은 느낌
5. [신규] 모든 화면 edge-to-edge + WindowInsets 패딩. 콘텐츠가 시스템 바에 깔리지 않게

## 3. 화면별 스펙 v2

### 대시보드 v5.0 (하단 탭 구조 — 현재 구현)
하단 탭 3개: 홈 / 위치관리 / 설정. 홈에는 결정 하나씩만 남긴다.
1. 헤더: 워드마크(딥 파인 그린 글로우 + 밑선) + "● 감지 중" + 차량 신호 진단 한 줄
2. 경과시간 바: "경과시간 · 주차 16:54" 왼쪽, 오른쪽에 H:MM 숫자 34sp **버건디**(이 화면의 포인트 한 곳)
3. 타일 2개(정사각): [엔진 버튼 층수 → 다시 기록/수동 기록] [주차 사진 → 크게 보기 / 없으면 내 차 아이콘 → 사진 찍기]
4. 지도 카드: [🔍][집][학교]… 칩 (탭 → 그 위치로 지도 이동, 검색 → 저장 위치 이름 매칭 → 없으면 지오코딩 핀)
   + OSM 지도(차 마커·내 위치 점선·거리 방향 필·P 핀), 탭 → 지도 앱
- 위치관리 탭: 등록 위치 목록 + "+ 추가", 탭 → 편집 모달(저장·휴지통 헤더), 주차 중 위치는 그린 테두리 + "지금 여기" 버건디 태그
- 설정 탭: 기존 설정 화면 임베드 (뒤로 버튼 없음)

### 대시보드 v4.2 (이전)
세 장의 카드가 세로로 쌓이고, 내용이 길어지면 화면 전체가 스크롤된다.
1. 헤더: 앱 이름(레터스페이싱) + 우측 "● 감지 중" 배지 + 아래 "마지막 차량 신호 · 시각 연결/끊김" 진단 줄
2. 주차 카드:
   - 좌: 엔진 스타트 버튼(층수 + PARKED) — 누르면 '다시 기록' (주차 전이면 수동 기록)
   - 우: 내 차 배지 — 앱 아이콘에서 고른 차종·색 그대로, 주차 중이면 네온 링 점등
   - 가운데 한 줄: 위치명 · 구역 · 메모
   - 하단: [사진 보기] [+02:19 경과시간 — 트립미터 표기, 디스플레이 폰트]
3. 지도 카드:
   - 상단: "위치" + 저장된 위치 칩(집·학교…, 가로 스크롤, 현재 위치는 네온 테두리) + "+" 추가 칩 — 탭하면 수정 모달
   - 본문: GPS 지도(OSM 타일, 다크 테마는 색 반전). 차 마커 + 내 위치 점 + 점선,
     좌하단 "차까지 320m · 북동쪽" 필과 방향 화살표. 프리뷰 전용 — 탭하면 지도 앱으로 길찾기
   - 내 위치는 화면 복귀 시 1회만 조회 (절대 규칙 6), 차 좌표는 주차 확정 시 1회 저장분
4. 설정 카드:
   - "설정 · 즐겨찾기" + 우측 "모든 설정 →"
   - ★ 즐겨찾기 행은 항상 표시 (많아지면 카드가 길어지고 전체 스크롤)
   - 왼쪽 아래 "▸ 더 보기" → 아코디언: 나머지 빠른 설정, 최근 주차 카드 토글, 내 차 블루투스, 배터리 예외
- 형광은 엔진 버튼 링 / 내 차 링 / 감지 LED / 현재 위치 칩 테두리까지 (절대 규칙 3의 상한 안에서 상태 표시에만)

### 대시보드 v2 (이전 스펙 — 참고)
위에서 아래 순서:
1. 헤더: 앱 이름(레터스페이싱 2px) + 우측 "● 감지 중" 형광 상태 배지
2. 메인 카드 (계기판):
   - 좌측: 원형 게이지 (형광 테두리 3px, 안에 층수 24px + "PARKED" 9px 라벨)
   - 우측: 장소명 / 구역+메모 (map-pin 아이콘) / 시각+경과 (clock 아이콘)
   - 하단: [사진] [다시 기록] 버튼 2개
3. 최근 주차 카드: 최근 2~3건 (날짜·장소 | 층). 탭하면 전체 히스토리 화면
4. 설정 카드: 접힌 상태가 기본, 탭하면 아래로 펼쳐짐 (인라인 토글)
   - 여기엔 자주 쓰는 토글 3개만: 기압 자동감지(베타) / 위젯+상태바 / 출차 시 자동 삭제
   - "모든 설정" 링크로 전체 설정 화면 진입
- 주차 기록 없을 때: 게이지가 회색, 안에 "—" 표시, "지금 주차 중이 아니에요"

### 기록 바텀시트 v5.1 (사용자 스케치 "기록 디자인" — 현재 구현)
한 장의 카드에서 끝낸다:
```
 위치정보  (집 ▾) | (⊕ 위치 등록)                         [ 주차 ]
        ◁    ┌────┐    ▷          ┆ 사진 ┆
       위층   │ B1 │   아래층        └ ─ ─ ┘
             └────┘
 메모 (예: C구역 기둥 27 옆) ____________________________ 🎤
 힌트: ◁ ▷로 층을 맞추고 주차 · 10초 무응답 시 위치만 저장
```
- 층은 ◁(위층) ▷(아래층) 스테퍼. 초기값 = 기압 추정 > 지난번 층 > B1. 지하 = 그린, 지상 = 버건디
- 위치 칩: 등록된 위치면 이름(탭 → 위치 선택), 처음이면 "⊕ 위치 등록"(탭 → 이름·층 구성 등록)
- 사진 슬롯(점선) 탭 → 카메라, 찍으면 썸네일. 메모 한 줄 + 음성 입력. 키보드 완료 = 주차
- [주차] 한 번으로 층·메모·사진 확정 → 설정에 따라 확인 카드 또는 완료 토스트
- 위치별 바텀시트 모드(층수만/층+메모/층+사진)는 흐름을 나누지 않는다 — 세 요소가 항상 한 카드

### 홈 위젯 v5.1
- 경과 시간은 **시간:분**(3:14). 주차 중에만 1분 부정확 반복 알람으로 갱신, 출차 시 해제
- 2x1: 한 줄 [B3] [3:14] — 세로로 쌓지 않아 낮은 셀에서도 위아래가 안 잘린다.
  가로 200dp 이상이면 "주차 16:54 · 집"을 덧붙인다 (SizeMode.Responsive). 세로 리사이즈 허용
- 1x1: 층수 위 / 경과 시간 아래, 카드가 셀을 채운다

### 팝업 (이전 스펙 — 참고)
- 다른 앱 사용 중에도 화면 하단 약 1/3을 덮는 바텀시트로 등장
  (SYSTEM_ALERT_WINDOW "다른 앱 위에 표시" 권한 — 온보딩 2단계에 추가)
- 시야를 살짝 가리는 게 의도: 불편해서라도 층 버튼을 누르게 됨
- 그 자리에서 층 버튼 바로 탭 — 모달 위 모달 금지
- 구성: 드래그 핸들 / "주차 감지 — 몇 층?" + 작은 카메라 버튼 /
  층 버튼 세로 스택 / 하단 힌트
- 기압 자동감지 켠 경우: 추정 층이 미리 형광 강조 + "기압 추정" 라벨. 탭 1번으로 확정
- 위로 쓸어올리면 확장 → 구역/메모 입력 필드
- 10초 무응답 → 시트 내려가고 "위치만 저장됨"
- 알림 권한만 있고 오버레이 권한 없는 유저 → 기존 헤드업 알림으로 폴백

### 상태바 표시 (v4.3 — 층 표지판)
- 모서리만 살짝 둥근 사각 표지판(코너 = 높이의 22%)에 층수를 크게. 캔버스를 거의 꽉 채우고
  글자는 실측으로 표지판 높이의 74%·폭 84%까지 채운다 (고정 크기 아님 — "B12"도 같은 비율)
- 글자는 색칠이 아니라 투명하게 뚫는다(cutout): 색 보존 기기(삼성 One UI 등)에선 컬러
  표지판 + 어두운 글자, 알파 실루엣만 취하는 기기에선 흰 표지판 + 글자로 양쪽 다 읽힌다
- **층별 색** — 색만 보고 층을 아는 것이 목적. 지상은 따뜻한 앰버, 지하는 차가운 라임 계열
  (FloorWheel의 지상 앰버/지하 네온 위계를 그대로 확장). 어두운 상태바에서 어두운 색은
  보이지 않으므로 구분은 명도가 아니라 색상으로 준다:
  | 지하 | B1 #C6FF00 라임 | B2 #76FF03 연두 | B3 #00E676 초록 | B4 #00E5FF 시안 |
  | 지상 | 1F #FFD54F 앰버 | 2F #FFAB40 오렌지 | 3F #FF7043 진한 주황 | 4F #FF5252 코랄 |
- 알림창 colorized 배경도 같은 층 색 — 상태바와 알림이 같은 신호를 준다
- 알림 확장 뷰: "B3 · C구역 · 기둥 27 옆 · 1시간 20분" + 경과 시간 크로노미터
- 층별 색은 상태바·알림에만 쓴다 (앱 화면은 절대 규칙 3: 형광 1~2개 유지)

### 홈 위젯 (v4.2 — 층수 + 경과 시간)
- 2x1: 다크 카드. 좌 층수(네온 32sp) / 우 **경과 시간 26sp(디스플레이 폰트, 살아서 흐름)** + 아래 "주차 13:43 · 장소" 11sp
- 1x1: 층수(네온 26sp) + 경과 시간 12sp
- 경과 시간은 RemoteViews Chronometer — 런처가 그리므로 앱은 깨어나지 않음 (배터리 규칙 7)
- 시스템 표기 규칙(1시간 미만 MM:SS, 이상 H:MM:SS) 때문에 주차 시각을 옆에 함께 둔다
- 주차 없을 땐 회색 "기록하기" 버튼 역할 (수동 기록 진입점)

### 앱 아이콘 (3안 중 택1, 모두 #1E1E1C 배경)
- A: 형광 자동차 실루엣
- B: 형광 테두리 P 사인 (주차 표지판)
- C: 건물 단면 3줄 중 가운데만 형광 + 미니 차 (시그니처 그래픽 연장) ← 추천
