# PRD v2 — 주차어디 (구 어따뒀지)

주차 위치(특히 지하 층수)를 하차 순간 자동 감지해 원터치로 기록하고, 상태바·홈 위젯에 상시 표시하는 안드로이드 앱.

## 0. v2 변경 로그

- 앱 이름: 어따뒀지 → 주차어디 (후보: 내차어디, 어디댔지 / 최종 확정 전)
- 팝업: 헤드업 알림 → 다른 앱 위 바텀시트 (오버레이 권한 필요, 알림 폴백 유지)
- 기압 자동감지: "하지 않는 것"에서 → 설정의 베타 옵션으로 승격
  (자동 확정이 아니라 추정 층을 미리 선택해주는 방식, 확정은 항상 사람 탭)
- 홈 위젯 추가 (상태바와 병행)
- 대시보드에 최근 주차 기록 + 인라인 설정 토글
- 층+메모 저장/표시 ("B3 · C구역 · 기둥 27 옆")
- 배터리 사용 최소화를 명시적 요구사항으로

## 1. 문제 정의 (유지)

- 주차 당시엔 기억할 것 같지만 볼일 보고 나면 기억나지 않는다. 다음날엔 거의 안 난다
- 지하 몇 층인지만 알아도 차 찾기가 훨씬 수월하다
- 기존 앱은 GPS 좌표 중심이라 지하 층수를 다루지 못한다

## 2. 핵심 가치 (유지)

"기록은 3초, 확인은 0초"

## 3. MVP 범위 v2

1. 하차 감지: 차량 BT 연결 해제 (내 차 MAC 필터) + 5초 재연결 필터
2. 팝업: 화면 하단 1/3 바텀시트, 층 버튼 세로 스택, 그 자리에서 원터치
   - 지난번 층 강조, 기압 추정 층 미리 선택(옵션), 10초 무응답 → 위치만 저장
   - 오버레이 권한 없으면 헤드업 알림 폴백
3. 상시 표시: 상태바 "P·B3" + 홈 위젯 (2x1 형광 필 / 1x1 게이지)
4. 자동 만료: BT 재연결 시 표시 제거, 기록은 히스토리 보관
5. 최근 주차 기록: 대시보드에 2~3건 + 전체 히스토리 화면 (Room DB)
6. 층+메모: 구역·기둥 메모 입력 (바텀시트 쓸어올리기 or 대시보드에서)
7. 기압 자동감지 (베타, 설정 토글):
   - 운전 종료 전후 기압 변화로 지하 층수 추정 (층고 약 3m ≈ 0.36hPa)
   - 정확도 ±1층 한계 → 반드시 "추정" 라벨 + 사람 탭으로 확정
   - 센서 샘플링은 주행 감지 중에만 (배터리)
8. 온보딩 3단계 + 오버레이 권한 추가 (총 4개 권한)
9. 배터리 최소화 (명시 요구사항):
   - 대기 중: BT 브로드캐스트 수신만 (폴링 금지)
   - GPS: 주차 확정 순간 1회만, 상시 추적 금지
   - 기압: 주행 중에만 저빈도 샘플링
   - 설정에 "배터리 사용 안내" 섹션으로 투명하게 공개
10. 수동 기록 (BT 없는 유저 + 위젯 진입점)

## 4. 앱 이름 결정 기준

- 검색 노출: "주차", "내차", "위치" 키워드 포함 여부
- 후보: 주차어디 (검색어 그 자체, 추천) / 내차어디 / 어디댔지 (개성)
- 피할 것: "내차찾기" — 동명/유사 앱 다수, 검색에 묻힘
- 결정 시 플레이스토어에서 중복 확인 필수

## 5. 2차 버전

- 주차요금 계산기, 기둥 번호 OCR, 가족 공유, iOS (Live Activity)

## 6. 하지 않는 것

- 기압 층수 "자동 확정" (추정+사람 확인까지만)
- 주차장 실내 지도/내비, 비콘 인프라 의존, 상시 위치 추적

## 7. 리스크 (유지 + 추가)

1. 제조사 절전 정책 (최대 리스크) — 실기기 테스트 1순위
2. 이어폰 오작동 → 내 차 MAC 필터
3. 오버레이 권한 거부감 → 온보딩에서 "이래서 필요해요" 스크린샷 + 알림 폴백
4. 기압 추정 오차 → "베타" + "추정" 라벨로 기대치 관리
5. 상태바 아이콘 시스템 단색 처리 → 형광 필은 위젯/잠금화면에서 구현

## 8. 수익 모델 / 9. 성공 지표 (유지)

무료·무광고 시작, 편의 기능 일회성 유료. 지표: 온보딩 완료율, 감지 성공률, 팝업 응답률, D7.
