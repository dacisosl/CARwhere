# 내차위치 랜딩페이지 기획서

> 목표: 방문자가 15초 안에 "아 이거 나잖아" → 스크롤 끝에서 "깔아야겠다"가 되게 만든다.
> 산출물: `docs/landing/index.html` 단일 파일 (셀프컨테인드) — GitHub Pages로 그대로 서빙 가능.

---

## 1. 핵심 전략

### 컨셉 — "그 순간을 재현한다"
설명하지 말고 **겪게 한다**. 방문자 전원이 이미 경험한 장면(지하주차장에서 차 찾아 헤매기)을
첫 화면에서 그대로 재현하고, 스크롤 한 번으로 해결책을 "점등"시킨다.
전형적 앱 소개("기능이 많아요")가 아니라 **문제 공감 → 반전 → 증명 → 전환**의 4막 스토리.

### 한 줄 가치 제안 (전 구간 반복)
> **기록은 3초, 확인은 0초.**

### 심리 장치
| 장치 | 적용 |
|---|---|
| 공감 후킹 | 첫 화면이 광고가 아니라 "내 이야기" — 이탈 방지 |
| 대비 연출 | 어둠(문제) → 네온 점등(해결) 시각 반전 |
| 숫자 신뢰 | 3초 / 0초 / 위치 조회 1회 / 무료·무광고 |
| 마찰 제거 | 스토어 아님, APK 한 번 탭 — CTA 상시 노출 |
| 소유 욕구 | "내 차랑 똑같은 아이콘" 12종 쇼케이스 |

### 톤 & 무드
앱과 100% 동일한 브랜드: 콘크리트 다크(`#1E1E1C`/`#2C2C2A`) + 네온 라임(`#AEEA00`),
레터스페이싱 라벨(PARKED), 지하주차장 사인 감성. 라이트 모드 없음(다크 고정 — 주차장이니까).

## 2. 페이지 구성 (스크롤 내러티브 8섹션)

### §0. 스티키 네비 (상시)
- 좌: 앱 아이콘(32px) + "내차위치"
- 우: `APK 받기` 네온 버튼 → `github.com/dacisosl/CARwhere/releases/latest`
- 스크롤 내려가면 반투명 블러 배경. **어느 지점에서든 전환 가능**하게.

### §1. Scene A — 문제 (100vh, 히어로)
- 배경: 어두운 지하주차장 (CSS 그라디언트 + 기둥 실루엣, 형광 사인 하나만 깜빡)
- 중앙: **캐릭터 에셋** (두리번거리는 컷) — 살짝 좌우로 흔들리는 모션
- 캐릭터 주변 부유 말풍선: `내 차 어디였지…?` `B1?` `B2였나` `B3…?` — 각기 다른 딜레이로 떠다님
- 하단 카피:
  - H1: **다들 한 번은 있잖아요.**
  - sub: 분명 여기쯤이었는데. 한 층씩 오르내리던 그 15분.
- 스크롤 유도: `▼ 그 날 이후로는` (바운스 애니메이션)

### §2. Scene B — 반전 (100vh)
- 진입 순간: 화면 전체 **네온 점등 연출** (형광등 2번 깜빡 → 켜짐)
- 좌: 초대형 타이포 **여기있다!!!** (네온 라임, 글로우) + 캐릭터 유레카 컷
- 우: **폰 목업** (HTML로 재현한 실제 대시보드 — B3 PARKED 네온 게이지, 장소·경과시간)
  - 폰 상태바의 `P·B3` 아이콘에 네온 서클 하이라이트 + 라벨 "앱 안 열어도 상태바에 항상"
- 카피:
  - H2: **기록은 3초, 확인은 0초**
  - sub: 차에서 내리면 앱이 먼저 물어봐요. 층 한 번 탭하면 끝.

### §3. How it works — 3스텝 (가로 3칸, 모바일 세로)
| 스텝 | 비주얼 | 카피 |
|---|---|---|
| ① 내리면 | 블루투스 끊김 아이콘 + 바텀시트 미니 목업 | **내리는 순간 알아서** — 차 블루투스가 끊기면 층 선택이 올라와요 |
| ② 탭 한 번 | 층 버튼 스택(B3 네온) + 메모 입력 | **B3, 탭.** 세부구역은 메모로 — "C구역 기둥 27 옆" |
| ③ 잊어버리세요 | 상태바 P·B3 + 위젯 2종 | **이제 폰이 기억해요** — 상태바·홈 위젯에 항상 |

### §4. 기능 그리드 (2×2 카드)
1. **가던 데는 더 빨라요** — 등록한 주차장(반경 150m)은 지난번 층을 먼저 보여줘요
2. **기압으로 층 추천** (베타) — 지하로 내려간 만큼 계산해서 미리 골라둬요
3. **홈 위젯 2종** — 형광 필 / 미니 게이지, 층수+주차 시각
4. **사진 한 장이면 확실** — 기둥 번호 찍어두기

### §5. 아이콘 쇼케이스
- 12종 차량 아이콘 가로 그리드 (에셋 재활용: `ic_fg_*.png`)
- 카피: **내 차랑 똑같은 아이콘으로** — 경차부터 스포츠카까지, 흰·검·회

### §6. 신뢰 스트립 (3칸)
- **무료, 무광고** — 수익모델로 괴롭히지 않아요
- **배터리 걱정 제로** — 폴링 없음 · 위치는 주차 순간 1회만 · 센서는 주행 중에만
- **오픈소스** — 코드 전부 공개 (GitHub 링크)

### §7. 최종 CTA + 푸터
- H2: **이제 그만 헤매세요**
- 초대형 네온 버튼 `APK 다운로드` + 옆에 QR 코드 (폰으로 바로)
- 캡션: Android 8.0+ · 설치 후 앱이 알아서 업데이트돼요
- 푸터: GitHub · 버전 표기

## 4. 모션 연출표

| 구간 | 트리거 | 연출 | 구현 |
|---|---|---|---|
| SceneA 말풍선 | 로드 | 각기 다른 딜레이로 떠오르고 둥둥 부유 | CSS keyframes (float, 딜레이 0/0.6/1.2/1.8s) |
| SceneA 캐릭터 | 로드 | 좌우 살짝 기울며 두리번 | CSS rotate ±3° 무한 |
| 형광 사인 | 로드 | 불규칙 깜빡임 (고장난 형광등) | CSS steps() opacity |
| A→B 전환 | 스크롤 진입 | 화면 플래시 2회 → 네온 점등, "여기있다!!!" 글로우 팝 | IntersectionObserver + class 토글 |
| 폰 목업 | 진입 | 아래서 슬라이드 업 + 상태바 아이콘에 서클 하이라이트 순차 | 동일 |
| 스텝/카드 | 진입 | stagger 페이드업 (80ms 간격) | 동일 |
| CTA 버튼 | 항상 | 네온 펄스 (은은한 글로우 숨쉬기) | CSS animation |

원칙: 모션은 스토리를 돕는 것만. 라이브러리 없이 CSS + IntersectionObserver.

## 5. 기술 스펙

- **파일**: `docs/landing/index.html` 하나 (CSS/JS 인라인, 이미지는 상대경로)
- **이미지**: 캐릭터 에셋 2컷 + 아이콘 12종(기존 `drawable-nodpi/ic_fg_*.png` 복사) + QR(생성)
- **폰 목업**: 스크린샷 대신 HTML/CSS로 대시보드 재현 (선명도·용량·유지보수 유리)
- **반응형**: 모바일 우선 (방문자 대부분이 폰) — SceneB는 모바일에서 세로 스택
- **다운로드 링크**: `https://github.com/dacisosl/CARwhere/releases/latest` (항상 최신)
- **호스팅(다음 단계)**: GitHub Pages — 레포 Settings → Pages → main `/docs` 지정하면
  `https://dacisosl.github.io/CARwhere/landing/` 로 즉시 서빙
- **OG 태그**: 제목 "내차위치 — 기록은 3초, 확인은 0초" + 프리뷰 이미지(SceneB 캡처)
